# Security

Never include API keys, SSH keys, browser profiles or private transcripts in issues. If reporting a vulnerability, use GitHub's private vulnerability reporting when available, or contact the repository owner privately before disclosing details.

API calls are made by the extension background worker to the user-configured HTTPS origin. Native hosts are optional and require an explicit extension ID. The example blog publisher is disabled until configured locally. Review native adapters before enabling them on a machine with production SSH access.
